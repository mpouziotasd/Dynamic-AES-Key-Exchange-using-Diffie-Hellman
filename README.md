# Dynamic-AES-Key-Exchange-using-Diffie-Hellman
A secure Alice / Bob communication example of Dynamic AES Key Exchanging using Diffie-Hellman method

## Requirements
python 3.8+, cryptography, pycryptodome

## Installation
```
conda create -n key-exchange python==3.8 -y
conda activate key-exchange

pip install -r requirements
```

## Execute
```
python main.py
```
